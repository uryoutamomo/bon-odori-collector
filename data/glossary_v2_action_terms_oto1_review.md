| 語 | 推定解釈 | メモ |
|---|---|---|
| 遠征 | 遠方の盆踊り・練習会へ踊りに行くこと | 「遠征4回目」など、踊り目的の移動として明確 |
| 飛び入り | 事前登録なしにその場で参加すること | 盆踊りの開放性を示す |
| 飛び入り専門 | 飛び入り中心で活動する参加スタイル | 自己認識として出ている |

| 見よう見まね | 周囲を見ながらその場で踊ること | 初心者・飛び入り参加と相性がよい |
| 初見 | 初めて見る/踊る曲や振り | `初見曲` とまとめてもよい |
| 予習 | 事前に曲や振りを覚えること | 会場参加前の準備行動 |
| 練習会 | 本番前/定期の踊り練習の集まり | かなり頻出 |
| 直前練習 | 本番直前の確認練習 | 練習会のサブタイプ |
| 音出し | 曲を流し、踊れる人が踊る自由度高めの場 | 盆踊り運用語として濃い |
| リード | 踊りの見本役/その役割 | 役割語としても扱える |
| 盆踊り巡り | 複数の盆踊り会場を回ること | `ハシゴ` に近い |
| 踊り流し | 行列や通りを進みながら踊る形式 | `流し踊り` と要整理 |
| 徹夜踊り | 夜通し踊る形式・参加行動 | 郡上/白鳥系文脈で重要 |

## 同義まとめ候補

| 代表候補 | まとめ候補 | 判断メモ |
|---|---|---|
| 踊りの輪に入る | 輪の中に入る / 内側 | `内側` は位置語として別行もあり |
| 盆踊り巡り | 盆踊り巡る / 行ったり来たり | `行ったり来たり` は一般語なので弱い |
| 踊り流し | 流し踊り | 地域差・形式差があるか内田さん確認 |
| 初見 | 初見曲 | 曲単位で残すなら別行 |
| リード | 櫓に上がる / 櫓上 | 役割語として別カテゴリ化してもよい |
| 所作で捨てる | 残す部分 | セットで意味が立つ |

## 弱候補

| 語 | 理由 |
|---|---|
| 踊り子 | 一般語でもあり、界隈語として採用するか要確認 |
| 踊ってきた | 参加報告シグナルとしては強いが、辞書語としては普通 |
| 行ったり来たり | ハシゴに近いが一般語 |
| 踊りきる | 参加完了シグナル。界隈語としては弱め |
| 櫓上 | `櫓に上がる` の名詞形として扱えそう |
| 残す部分 | `所作で捨てる` とセットなら有効 |
| 踊りやすい | 評価語寄り |
| 踊りにくい | 状況語寄り |
| たっぷり踊る | 参加量の表現。感情語寄り |
| お暇 | 丁寧な退出表現。盆踊り固有度は弱い |

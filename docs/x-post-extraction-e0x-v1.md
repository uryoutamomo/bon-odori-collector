# E0X: X投稿からE0レポートを作る器 v1.1

`voices.json` のX投稿を、意味語による間引きなしでLLM採点用packetへ分割する。回答は本文・日付・会場・引用・URLを機械照合し、5点かつ未来日のものだけを既存 `official_notice` 形式で `data/x_post_reports/` に出す。

同じ正規化済みイベント名・開始日・会場は1レポートへ束ねる。初回投稿を代表として固定し、後続投稿は出典URLだけを内部行へ追加する。stateは発行と処理を分け、24時間以内の回答待ちは二重発行せず、未回答は翌日に再発行する。

詳細な合意仕様は `x-post-extraction-e0x-v1.md`（おと・こと共有メッセージ）を正本とする。

# NotionイベントDB整理記録

日付: 2026-06-07

## 目的

DB分割後も残っていた旧イベントDBと旧relationを整理し、イベント情報と
参加計画の正本を明確にする。

## 正本

- イベント: `🎆 イベントDB`
  - data source `a83b5a63-7411-4d6a-8bbc-83bedf4e7b5d`
- 参加計画: `🗓️ 参加計画`
  - data source `6a29d662-cd27-487f-9d76-5a57239b1aa2`

参加計画からイベントへの `イベント` relationを正規の接続方向とする。

## 実施内容

- 旧 `🎆 イベントマスター` 35件を現行イベントDBと照合
- 旧 `盆踊りイベント（共通）` 16件を現行イベントDBと照合
- 51件すべてに現行イベントDBの対応ページがあることを確認
- 旧イベント51件を復元可能なアーカイブへ移動
- 旧Data Source名に `旧・移行済み・使用禁止` を付与
- 空の旧参加計画Data Source名に `旧・空・使用禁止` を付与
- 現行イベント16件に残っていた旧参加計画relationの値を解除
- 現行イベントDBから旧relationプロパティ `参加計画` と
  `参加計画 1` を削除

共有解除済みの旧 `🗓️ 参加計画DB（内田）` はAPIから改名できなかった。
その配下で確認済みの旧参加計画ページはすでにゴミ箱へ移動済み。

## 検証結果

- 現行イベントDB: 59件
- 現行参加計画: 16件
- 現行参加計画16件はすべて現行イベントDBを参照
- 旧イベントマスターのアクティブ行: 0件
- 旧「盆踊りイベント（共通）」のアクティブ行: 0件
- 現行イベントDBの残存プロパティ:
  - イベント名
  - 会場

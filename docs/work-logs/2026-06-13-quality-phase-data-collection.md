# 2026-06-13 品質改善フェーズ: イベント収集強化

## 背景

一般公開前に、データ精度を優先して改善する方針に切り替えた。
主な課題は、未収集イベントの多さ、イベントに対応した曲確率の低さ、曲マスター不足、フロントエンドデザイン改善。

## 実施内容

- X 収集予算を一時的に 3 倍へ変更。
  - `daily_usd`: 1.0 -> 3.0
  - `monthly_usd`: 5.0 -> 15.0
- 通常 X 検索の深さを拡大。
  - `max_pages_per_query`: 2 -> 3
- イベント断片の履歴収集を継続モードへ変更。
  - `pilot_only`: true -> false
  - `max_pages_per_run`: 60 -> 120
  - `max_evidence_per_run`: 300 -> 900
- 収集クエリを追加。
  - 今年の開催予定・日程告知
  - ポスター・チラシ・町会/自治会告知
  - 曲目・演目・練習会/講習会
- 定番イベントの能動検索範囲を拡大。
  - `lead_months`: 1 -> 2
  - `max_targets_per_run`: 12 -> 36
  - `max_x_queries_per_run`: 6 -> 18
- 停止していたイベント断片収集窓を次へ進めた。
  - `2025-07-08` から `2025-07-22` まで

# Notion安全性向上バッチ

日付: 2026-06-07

## 目的

イベント・参加計画の正本確定後に残った小規模な不整合をまとめて修正し、
誤接続、重複登録、古いGoogle Calendar予定の残存を早期検知する。

## コード変更

- `notion_config.py`
  - イベント、参加計画、会場のData Source IDとDatabase IDを一元管理
  - ローカル `.env` 読込を依存ライブラリなしで提供
- `notion_api.py`
  - Notion Data Source APIクライアントを追加
  - ページング、ページ取得・更新、スキーマ検査を共通化
- `event_audit.py`
  - イベント名と情報源URLによる重複監査を追加
  - 一覧ページを共有する異なるイベントは警告として分離
- `sync_gcal.py`
  - 旧Database APIと旧イベントスキーマへの依存を廃止
  - 現行イベント・参加計画・会場Data Sourceへ対応
  - 実行前のスキーマ、relation、重複検査を追加
  - `確認済み` かつ開催日ありのイベントだけを同期
  - 未確認化または日程削除時に既存Google Calendar予定を削除
  - 終日予定の終了日をGoogle Calendarの排他的仕様に合わせて補正
- GitHub Actions
  - 日次収集前にイベントDB監査を実行

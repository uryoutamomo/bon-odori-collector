# 過去開催回の曲目と対象年切替の検証

2026-09-09 / おと（Codex）

2027年へ対象年を進めると、2026年には当年カードへ置換されていた2025年の四谷納涼踊り大会が
公開候補に残り、曲目 `current_hint=95` の監査で4出力とも生成できなかった。
R2の構造整理と独立して、残存する過去開催回の曲目を対象年へ換算した。

## 修正範囲

- 古い開催回と曲名を残す。RDB、根拠、固定入力を書き換えない。
- 置換・曲目補完を終えた後、残った開催回の `_event_year` から対象年まで年差減衰する。
  表示日が過去実績日でも当年開催回なら再減衰しない。
- 直接根拠は話者係数を1回だけ掛け、`0.75 ** 年差` で換算する。
  継承済みの `past_evidence` は追加の年減衰だけで、複数年の根拠ラベルを保持する。
- 当年・未来・開催年不明の曲は変更しない。当年ヒント95%の監査拒否を維持し、範囲外確率も拒否する。
- コード修正commit: `0389e838b3b1bfbf4ffa16e0ba1deba8b57cf8e9`。
  同じPR内の別commitで仕様と本記録を更新する。

## R2との組合せ検証

R2の比較器で、元capture commitとR2側の両隔離snapshotへ上記コードcommitの同一patchを適用した。
`shared_code_fix_parity` として、通常日・終了前日/当日/翌日・過去実績スライド当日/翌日・
年末・年始（対象年固定/翌年へ進める）の9ケースで4出力がbyte一致した（36比較）。
これは修正を共通前提にした構造比較であり、修正前の監査停止を合格に読み替えない。

- 組合せ全体テスト: **1,900 passed / 240 subtests passed**。
- 年越しと既存exporterの重点テスト: **62 passed**。
- 6 mutationで、処理呼出し欠落、年差無視、話者係数再適用、表示年の誤採用、当年への誤適用、
  当年カードと同居する過去カードの換算漏れをすべて検出した。
- 独立レビューで二重減衰、監査維持、実経路のテストを確認した。
